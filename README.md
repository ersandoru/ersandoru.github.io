# Ersan Doru - Personal Profile Website

This repository contains the source code for my personal profile website, built with Jekyll and hosted on GitHub Pages.

The live site can be viewed at: [https://ersandoru.github.io/](https://ersandoru.github.io/)

## ✨ Features

*   **Responsive Design**: Looks great on desktop and mobile devices.
*   **Dark Mode**: A user-toggleable dark theme for comfortable viewing.
*   **Dynamic Content**: Experience, projects, skills, and education are managed via simple YAML data files in the `_data` directory.
*   **Animations**: Subtle fade-in animations on scroll for a modern feel.

## 🛠️ Built With

*   Jekyll - A simple, blog-aware, static site generator.
*   Minima Theme - The base theme, which has been heavily customized.
*   Sass - For structured and maintainable CSS.
*   GitHub Pages - For hosting.

## 🚀 Running Locally

To run the site on your local machine, you'll need to have Ruby and Bundler installed.

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/ersandoru/ersandoru.github.io.git
    cd ersandoru.github.io
    ```

2.  **Install dependencies:**
    ```bash
    bundle install
    ```

3.  **Run the Jekyll server:**
    ```bash
    bundle exec jekyll serve
    ```

4.  **Open your browser** and navigate to `http://localhost:4000`. The server will automatically rebuild the site whenever you make changes to the source files.
